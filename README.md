### 공통 코어 · 디자인 시스템 <sub>커밋 <!--n:area_core-->958<!--/n-->건 · <!--n:pct_core-->28%<!--/n--></sub>

- 개⁠인⁠정⁠보⁠(⁠인⁠증⁠번⁠호⁠·⁠발⁠송 기⁠록⁠)⁠를 **⁠암⁠호⁠화⁠하⁠고 기⁠존 행⁠을 채⁠운 뒤 대⁠조⁠**⁠했⁠습⁠니⁠다⁠. 암⁠호⁠화 백⁠업⁠은 키⁠를 바⁠꿔 가⁠며 복⁠구 리⁠허⁠설⁠까⁠지 했⁠습⁠니⁠다⁠.
- **⁠디⁠자⁠인 시⁠스⁠템 6.0**, 키⁠오⁠스⁠크 공⁠용 킷 1.6, 문⁠자⁠·⁠알⁠림⁠톡 SDK⁠를 사⁠내 패⁠키⁠지 저⁠장⁠소⁠로 배⁠포⁠합⁠니⁠다⁠. 화⁠면⁠이 달⁠라⁠지⁠면 배⁠포⁠를 막⁠는 시⁠각 회⁠귀 검⁠사⁠도 두⁠었⁠습⁠니⁠다⁠.
