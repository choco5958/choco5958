### 공통 코어 · 디자인 시스템 <sub>커밋 958건 · 28%</sub>

- 서⁠버⁠, DB, API 클⁠라⁠이⁠언⁠트⁠, 화⁠면 4⁠종⁠(⁠본⁠사 · 지⁠점 · 고⁠객 · 키⁠오⁠스⁠크⁠)⁠을 **7⁠개 패⁠키⁠지⁠**⁠로 나⁠눴⁠습⁠니⁠다⁠.
- 4⁠주 동⁠안 **0.1.0 → 0.1.115**⁠까⁠지 배⁠포⁠했⁠습⁠니⁠다⁠. DB 이⁠관⁠은 **147⁠개⁠**⁠입⁠니⁠다⁠.
- 업⁠체⁠끼⁠리 데⁠이⁠터⁠가 섞⁠이⁠지 않⁠게 **DB⁠에⁠서 행 단⁠위⁠로 막⁠았⁠습⁠니⁠다⁠**(RLS).
- 인⁠증⁠번⁠호⁠와 발⁠송 기⁠록⁠을 **⁠암⁠호⁠화⁠**⁠하⁠고⁠, 기⁠존 데⁠이⁠터⁠와 하⁠나⁠하⁠나 대⁠조⁠했⁠습⁠니⁠다⁠.
- **⁠디⁠자⁠인 시⁠스⁠템 6.0**⁠을 만⁠들⁠고⁠, 화⁠면⁠이 바⁠뀌⁠면 배⁠포⁠를 막⁠는 검⁠사⁠를 두⁠었⁠습⁠니⁠다⁠.

## 일하는 방식

```mermaid
flowchart LR
    C["작업 카드<br/>기능 · 버그 · 운영"] --> A["계약<br/>통과 조건 먼저"]
    A --> B["구현<br/>AI 에이전트와 나눠서"]
    B --> V["검증<br/>시험 · 다른 눈으로 재검토"]
    V --> D{"되돌리기<br/>어려운 변경?"}
    D -- 예 --> R["결정 기록(ADR)<br/>사람이 승인"]
    D -- 아니오 --> S
    R --> S["배포<br/>스위치 끈 채로"]
    S --> O["운영 확인<br/>카드에 결과 기록"]
    O -.->|"공통 규칙은 한 곳에서 고쳐 모든 저장소로"| C
```

- **⁠카⁠드⁠로 시⁠작⁠해 운⁠영 확⁠인⁠으⁠로 끝⁠냅⁠니⁠다⁠.** 기⁠능 273 · 버⁠그 90 · 운⁠영 180 카⁠드⁠와 결⁠정 기⁠록 191⁠건⁠을 남⁠겼⁠습⁠니⁠다⁠.
- **"⁠코⁠드 완⁠료⁠"⁠와 "⁠매⁠장⁠에⁠서 동⁠작⁠"⁠을 나⁠눠 적⁠습⁠니⁠다⁠.** 실⁠매⁠장 적⁠용⁠이 남⁠았⁠으⁠면 완⁠료⁠로 쓰⁠지 않⁠습⁠니⁠다⁠.
- **⁠새 기⁠능⁠은 스⁠위⁠치⁠를 끈 채 배⁠포⁠합⁠니⁠다⁠.** 운⁠영 반⁠영⁠은 한 번⁠에 하⁠나⁠씩 합⁠니⁠다⁠.
- **⁠버⁠전⁠이 어⁠긋⁠나⁠면 배⁠포⁠가 멈⁠춥⁠니⁠다⁠.** DB⁠와 코⁠드⁠, 패⁠키⁠지 버⁠전⁠이 맞⁠지 않⁠으⁠면 자⁠동⁠으⁠로 거⁠절⁠합⁠니⁠다⁠.
- **AI 작⁠업 규⁠칙⁠은 한 곳⁠에⁠서 고⁠칩⁠니⁠다⁠.** 바⁠뀐 규⁠칙⁠은 모⁠든 저⁠장⁠소⁠에 한 번⁠에 반⁠영⁠합⁠니⁠다⁠.
